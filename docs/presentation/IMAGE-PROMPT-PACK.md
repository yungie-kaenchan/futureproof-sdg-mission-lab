# FUTUREPROOF — Slide Background Image-Prompt Pack
### For Gamma.app · text-free backgrounds with reserved space for your own text
### Generate in Nano Banana (Gemini 2.5 Flash Image) or ChatGPT Image · 16:9 widescreen

---

## How to use this (read once)
1. **Keep the STYLE PREFIX constant.** Paste it before every slide's subject (or, in Nano Banana, set it once and keep generating). It's what makes all 24 slides look like one designed system instead of 24 separate experiments.
2. **Every image is text-free on purpose.** You add all English text in Gamma, in the empty zone each prompt reserves.
3. **Generate 16:9, highest resolution available** (≥1920×1080). In Gamma: set the image as the **card/slide background (full-bleed)**, then drop text boxes into the clear zone.
4. **Some slides use the REAL platform, not AI** (marked 🖥️) — screenshots / your pilot video clips. Don't generate those; place them on a plain deep-navy `#071734` Gamma background.
5. **3 slides get Google Flow motion** (marked 🎬): S1, S7, S23 — generate the still first, then animate it in Flow.
6. **Gamma tip:** set the deck theme to a **dark background + gold accent**; for fonts use a high-contrast serif for display (Fraunces / Playfair Display / EB Garamond) + DM Sans for body, to match the brand.
