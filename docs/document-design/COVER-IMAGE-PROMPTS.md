# FUTUREPROOF — Document Cover-Image Prompts (ChatGPT Image)

Eight cover images, one per submission document. Each is designed as a **landscape banner**
that sits at the top of the document's cover page (the Word template embeds it at ~166 mm wide).

## How to use
1. In ChatGPT, attach nothing — just paste one prompt per image.
2. Ask for **landscape 3:2 (1536 × 1024)**.
3. Save the result as the exact filename given (e.g. `read-this-first.png`) into
   `docs/document-design/covers/`.
4. Re-run the document's build script — the cover slots in automatically.

---

## HOUSE STYLE (applies to all eight — already baked into each prompt)

**Aesthetic:** "Mission Control × Editorial Elegance." Cinematic, photographic, fine-art realism —
**not** 3D render, **not** cartoon, **not** flat vector illustration, **not** clip-art. Think the
cover of a serious design or policy journal: restrained, premium, intentional.

**Palette (strict):** deep obsidian navy `#0A0A0B`–`#071734` as the dominant ground; warm
antique gold `#C9A961` as the single luminous accent; one controlled touch of deep crimson
`#7B1B1B` where noted; soft bone/cream `#FDFBF6` for any light passages. Muted, sophisticated,
high-contrast but never garish.

**Light:** low-key, directional, cinematic — a single warm gold key light raking across texture,
deep shadow falloff, subtle volumetric haze. Fine film grain. Shallow depth of field.

**Composition:** generous negative space, especially toward the centre-left or lower third, so
the document's printed title can breathe above it. Editorial, balanced, calm.

**Absolutely avoid:** any lettering, words, numbers, logos, watermarks, or UI text (the document
adds its own title — AI-rendered text will look garbled); people's faces in sharp focus; stocky
"corporate handshake" clichés; rainbow SDG-wheel logos; neon/cyberpunk; busy collage; cartoon
mascots; 3D-Pixar styling.

## Optional: a matching set look
For a cohesive "boxed set," generate all eight with the same camera language (same focal length
feel, same gold key-light direction from the right or left, same grain). If you want them even
tighter as a series, append to any prompt:
> *"Part of a matched set of eight document covers sharing identical lighting, palette, grain, and
> negative-space placement; consistent house style."*
