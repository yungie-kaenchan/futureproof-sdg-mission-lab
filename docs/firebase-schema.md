# Firebase Realtime Database Schema

**FUTUREPROOF: SDG Mission Lab — Data Architecture v1**

This document defines the data model for the FUTUREPROOF platform on Firebase Realtime Database. It is the source of truth for paths, types, indexes, and write contracts.

---

## 1. Design Principles

1. **PDPA-first.** No personally identifiable information (PII) is stored alongside operational data unless consent has been recorded. PII lives in `/users/$uid/profile/private`, gated by per-flag consent.
2. **Append-only where possible.** Decision logs and rubric scores are write-once, time-stamped. Edits create a new revision rather than overwriting history.
3. **Denormalized for read efficiency.** Realtime DB rewards shallow reads; we denormalize team membership and active mission state into `/teams/$tid`.
4. **Bounded under realistic load.** No path is expected to exceed 100K children at first-round scale (~500 students × 6 missions × ~30 decisions). If we cross that, we shard by class cohort.
5. **Server time only.** All `*At` timestamps use `firebase.database.ServerValue.TIMESTAMP` — never client clocks.

## 3. Collections

### 3.1 `/users/$uid`

Created on Firebase Auth account creation. Split into `profile/public`, `profile/private`, and `learnerProfile`.

```json
{
  "users": {
    "$uid": {
      "profile": {
        "public": {
          "displayName": "Aira",
          "avatarUrl": "gs://futureproof/avatars/$uid_v3.png",
          "rank": "fieldAgent",
          "joinedAt": 1747000000000,
          "institution": "MUIC"
        },
        "private": {
          "email": "encrypted:...",
          "fullNameTh": "encrypted:...",
          "fullNameEn": "encrypted:...",
          "yearOfStudy": 2,
          "consentVersion": "2026-05-12",
          "lastActiveAt": 1747100000000
        }
      },
      "learnerProfile": {
        "cefrEstimate": "B1",
        "vocabularyScore": 72,
        "criticalThinkingPercentile": 64,
        "analyticalPercentile": 71,
        "collaborationOrientation": 0.78,
        "assessedAt": 1747000010000,
        "version": 1
      },
      "roleAssignments": {
        "$tid": "researchAnalyst"
      }
    }
  }
}
```

**Notes:**
- `email`, `fullName*` fields encrypted at rest using a field-level cipher; key rotation handled by `adminConfig/keys`.
- `rank` enum: `cadet | fieldAgent | analyst | strategist | director | ambassador`.
- `learnerProfile` is **never** exposed to peers — read by user, their teachers, and AI prompt generation only.

### 3.10 `/tokens/$tid`

Append-only ledger.

```json
{
  "tokens": {
    "$tid": {
      "balance": 47,
      "ledger": {
        "$entryId": {
          "ts": 1747011500000,
```

## 5. Indexed Fields

For Realtime DB query performance, the following are declared as `.indexOn`:

| Path | Indexed Fields |
|---|---|
| `/teams` | `classId`, `currentMission`, `selectedSDG` |
| `/scenarios` | `sdg`, `frozen` |
| `/decisions/$missionId` | `ts`, `byUid` |
| `/rubricScores/$tid/$rubric` | `evaluatorRole`, `isFinal` |
| `/hallOfExcellence` | `featured`, `approvedAt`, `tid` |

---

## 6. Retention & Deletion

Per `adminConfig.deletionSchedule.afterDays` (default 90):

1. PII fields under `/users/$uid/profile/private` are tombstoned (replaced by `{ "deletedAt": ts }`).
2. Decisions, rubric scores, and reflections are anonymized (uids → hashed pseudonyms).
3. Pitch Capsule artifacts are retained only if Hall of Excellence consent is on file; otherwise deleted.
4. Audit logs persist 7 years per institutional policy.

A user-initiated deletion request via the "My Data" panel triggers immediate execution of steps 1–3.
